使用说明

连接微信并开始交互

cc-wx 将微信消息转发给本机 Codex，并把结果返回到微信。

  1. 添加微信账号点击页面右上角“添加微信”，使用微信扫描二维码并确认登录。
  2. 完成联系人授权登录后，从微信向账号发送一条消息；回到账号页允许该联系人的访问请求。
  3. 创建或选择会话在会话管理中创建工作会话，绑定允许的工作目录，再从微信发送普通消息。
  4. 继续处理任务普通消息进入当前活动会话，Codex 的回复、过程进度和可回传文件会返回到微信。

功能概览

当前版本支持的主要能力。

  • 支持多个微信账号，每个账号拥有独立授权、附件、会话和运行状态。
  • 支持文本、图片、语音、视频和文件输入；Codex 可回传本机图片、视频和文件。
  • 管理页支持账号、会话、工作目录、模型、推理强度和过程进度管理。
  • 新会话和续接会话优先使用 Codex app-server，必要时回退到 codex exec。
  • 过程进度默认开启，并支持消息去重、断线恢复和账号历史保留。

微信命令

在已授权的微信联系人中发送以下命令。

/help
查看命令帮助
/status
查看模型、思考强度、工作目录、会话 ID 和沙箱权限
/work [编号]
列出或切换允许列表内的工作目录
/new
创建新的受管 Codex 会话
/resume
查看历史会话
/resume R<编号>
继续指定的历史会话
/model
查看或切换模型
/effort
查看或切换推理强度
/stream
开启或关闭过程进度
/start
开始缓冲多条消息
/end
提交缓冲内容
/stop
中断当前任务

消息与文件

普通消息进入当前活动会话，附件会保存到对应微信账号的入站目录，并以本地路径加入 prompt。语音消息优先使用微信转写文本。
